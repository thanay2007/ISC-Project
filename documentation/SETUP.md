# Setup and troubleshooting

## Install dependencies

Use 64-bit Python 3.12 or 3.13 and Node.js 22. Run commands from the repository root. PaddleOCR is optional for local development. Omit `-r backend/requirements-ocr.txt` if Paddle wheels are unavailable for your platform.

### Windows PowerShell

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt -r backend/requirements-ocr.txt
.\.venv\Scripts\python.exe -m pip install --index-url https://download.pytorch.org/whl/cpu 'torch>=2.8,<3'
npm.cmd --prefix frontend ci
.\.venv\Scripts\python.exe backend/setup_env.py
~~~

### macOS and Linux

~~~bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt -r backend/requirements-ocr.txt
.venv/bin/python -m pip install 'torch>=2.8,<3'
npm --prefix frontend ci
.venv/bin/python backend/setup_env.py
~~~

The setup script creates the root `.env` with a unique application secret and encryption key. Keep these values with your database backups. The setup script preserves an existing `.env`.

## Choose a database and start

### Local SQLite

The launchers can use `.verifex/verifex.sqlite3` for one run. This option provides a persistent local workspace and leaves `.env` available for your Supabase settings.

~~~powershell
.\run.ps1 -LocalDatabase
~~~

~~~bash
bash ./run.sh --local-database
~~~

To make SQLite the default, put `DATABASE_URL=sqlite:///./.verifex/verifex.sqlite3` in `.env` and run the launcher without flags. SQLite and Supabase have separate users, reports, and issuance records. Moving those records between databases requires a data migration.

### Supabase PostgreSQL

1. Open the active project in the Supabase Dashboard and choose **Connect → Session pooler**. Copy the entire connection string for port `5432`, including the dashboard-provided username and hostname.
2. Replace the password placeholder with your database password. Percent-encode reserved characters within the password, such as `@` as `%40` and `#` as `%23`. Set the completed URL as `DATABASE_URL` in the root `.env`.
3. Run `.\run.ps1` in PowerShell or `bash ./run.sh` in Bash. In VS Code, Code Runner can also launch `run.ps1` in a PowerShell terminal.

VERIFEX accepts the dashboard's `postgresql://` URL and defaults to TLS for Supabase. Startup uses the configured database role to apply Alembic migrations, so use a direct or session-mode connection with schema permissions. Use the Session pooler on IPv4-only networks. [Supabase connection guide](https://supabase.com/docs/guides/database/connecting-to-postgres)

### Verify startup

Open the workspace using the exact origin configured in `PUBLIC_URL`, which defaults to `http://localhost:3000`. The health endpoint should return `"status": "ok"`. During development, port `3000` serves Next.js and proxies API requests to Uvicorn on `127.0.0.1:8000`. Press Ctrl+C in the launcher terminal to stop. [Workspace](http://localhost:3000) · [Health endpoint](http://localhost:3000/api/health)

## Environment variables

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | PostgreSQL connection string or SQLite path. A value exported in the shell takes precedence over `.env`. |
| `APP_SECRET_KEY`, `ENCRYPTION_KEY` | Generated by setup. They protect session tokens, derive the PDF report signing key, and encrypt private evidence and issuer keys. |
| `PUBLIC_URL` | Browser origin for write requests and base URL for public verification links. |
| `COOKIE_SECURE` | Set to `true` with an HTTPS public origin. |
| `DEMO_ENABLED` | Set to `true` to seed fictional records and enable the demo. The local template enables it. |
| `OCR_ENGINE`, `TESSERACT_CMD` | Use `auto` for PaddleOCR with fallback, or `tesseract` to use an installed Tesseract binary. Set the executable path if it is outside the system PATH. |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | Optional Gemini visual analysis. Set both to enable it. |
| `GROQ_API_KEY`, `GROQ_MODEL` | Optional Groq explanations and report questions. Set both to enable it. |
| `CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` | Optional Clerk sign-in. Enable the Google and Apple connections in the Clerk app, copy both keys, and restart. Only the publishable key is served to the browser. |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Set the verified email before the first Clerk administrator sign-in. A password of at least 12 characters seeds a password-based administrator if the account does not exist. For Clerk-only setup, leave the password blank. |
| `API_ORIGIN` | Next.js environment variable for the FastAPI proxy target. Start Next.js with this set when using a different backend address. The local launch default is `http://127.0.0.1:8000`. |

Choose models available to your provider account. Gemini receives rendered page images when configured. Groq receives structured findings and report questions. With provider settings blank, the local pipeline and reports still run. [Gemini models](https://ai.google.dev/gemini-api/docs/models) · [Groq models](https://console.groq.com/docs/models) · [Clerk setup](https://clerk.com/docs/getting-started/quickstart/setup-clerk)

## Warm the OCR models

The API warms PaddleOCR in the background. Its first run may need to download English detection and recognition models. Before a demo, run this from the repository root in PowerShell.

~~~powershell
$env:PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK = 'True'
.\.venv\Scripts\python.exe -c "from backend.verifex.ocr_service import OCR; OCR().warm()"
~~~

On macOS or Linux, use `.venv/bin/python` for the same Python command. In auto mode, OCR can fall back to Tesseract or visible text embedded in a PDF. Scanned images need a working raster OCR engine to extract text.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| `getaddrinfo failed` or `Could not translate host name` | Confirm the host in Supabase **Connect → Session pooler**. Run `Resolve-DnsName <pooler-host> -Type A` in PowerShell using the copied hostname. Check the network or VPN if the valid host cannot resolve. Use the SQLite launch flag if you need to work locally during an outage. |
| Database connection times out | After DNS resolves, run `Test-NetConnection <pooler-host> -Port 5432`. Verify the project is active and your network can reach the database port. |
| PostgreSQL authentication or tenant error | Recopy the username and host from the same connection string, confirm the database password, and check its percent encoding. Check whether a shell variable is overriding `DATABASE_URL`. |
| Port `3000` or `8000` is in use | Stop the earlier launcher with Ctrl+C in its terminal, or use the existing workspace if it is healthy. |
| Write request returns HTTP 403 | Confirm that the browser origin matches `PUBLIC_URL`. API clients also need `X-Verifex-Request: 1` and a role permitted for that route. |
| OCR unavailable or warming | Check `paddle_status` in the health response and the API logs. Preload PaddleOCR or configure Tesseract in `.env`. |
