# VERIFEX

VERIFEX analyzes uploaded PDFs and images, including certificates, invoices, receipts, and bills. It extracts text, marks possible signs of editing, and produces a forensic report with a visual assessment. An issuer can register and sign an original document so a verifier can compare an upload against that record.
